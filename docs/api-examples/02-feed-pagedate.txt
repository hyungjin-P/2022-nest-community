# 02 기준 시각(pageDate) 고정 피드 목록 — GET /feed/findPages (stage1 8절 근거 1·2)
# 클라이언트가 첫 요청 시각 pageDate 를 들고 다니고 서버는 sortedAt ≤ pageDate 로 자른다(feed.service.ts:53-67).
# 시나리오: 1페이지를 받은 뒤 다른 회원이 새 글을 게시 → 같은 pageDate 로 2페이지 / 새 pageDate 로 2페이지를 비교한다.
# isLike·isBookmark 는 페이지의 feed id 배열로 IN 조회 1회 후 매칭한 결과다(근거 2, feed-like.repository.ts:16-27). 쿼리 수 자체는 응답으로 보이지 않는다.
# 한계(stage1 9절 1): 로그인 사용자를 userId 쿼리로 받는다. 9절 2: likeCount·commentCount·pictureCount 는 피드마다 count() 한다.
