# 01 이메일 로그인 — POST /auth/signIn (stage1 4절 인증 흐름)
# 로그인 4종이 AuthService.createTokens 로 모여 accessToken·refreshToken(JWT)·Firebase custom token 을 사용자 엔티티에 섞어 돌려준다(auth.service.ts:289-341, :390-399).
# customToken 은 목업 값(mock-firebase-custom-token.<userId>)이다. JWT 는 원본 하드코딩 secret 으로 서명돼 값을 가렸다.
# 한계(stage1 9절 1·5): 토큰을 발급하지만 검증하는 가드가 0개다. 사용자 오류에도 HTTP 500 을 쓴다.
# 실행: 2026-10-17T13:46:07.095Z · 목업 서버 http://localhost:3000 (npm run mock:db:seed 직후 01→04 순서)
#
# 요약
#  01-a 201 · password 필드 없음(delete user.password) · 토큰 3종 있음
#  01-b 500 · failure / 비밀번호가 일치하지 않습니다.
#  01-c 500 · failure:deleted · message = 사용자 id(클라이언트가 /user/withdrawalCancel 에 쓴다)
