# 03 공백을 무시하는 태그·주제 검색 (MySQL REGEXP) — stage1 8절 근거 6
# 컬럼에서 공백을 지우고 REGEXP 로 매칭, GROUP BY 로 태그별 사용 수를 붙인다(feed-tag.repository.ts:17-30, magazine-tag.repository.ts:6-20, topic.service.ts:17-32).
# 주제 검색만 입력의 공백을 [[:space:]]? 로 바꾼다(첫 공백만, topic.service.ts:21). 피드·매거진 태그는 입력 쪽 공백을 지우지 않는다.
# 한계(stage1 9절 4): 입력을 이스케이프 없이 REGEXP 에 넣어 "(" 같은 문자가 쿼리 오류(500)를 낸다. MySQL 전용 문법이다.
# 실행: 2026-10-17T13:46:10.120Z · 목업 서버 http://localhost:3000 (npm run mock:db:seed 직후 01→04 순서)
#
# 요약
#  03-a 피드 태그 "보드게임" → [{"name":"보드 게임","tagCount":"2"},{"name":"보드게임","tagCount":"1"}]
#  03-b 매거진 태그 "다크나이트" → [{"nameEn":"Dark Knight","nameKo":"다크 나이트","tagCount":"1"}]
#  03-c 매거진 태그 "darkknight" → ["다크 나이트"]
#  03-d 주제 "홈베이킹" → ["홈 베이킹"]
#  03-e 주제 "홈 베이킹" → ["홈 베이킹"]
#  03-f 피드 태그 "보드 게임" → [] (입력 공백은 지우지 않아 매칭 0건)
#  03-g 피드 태그 "보드(" → 500 {"statusCode":500,"message":"Internal server error"}
